        |   quality_gate.py (ffprobe + ffmpeg)

        |   Gemini reads the spec JSON (not the video) and scores 6 dimensions:
        |     factual_accuracy  — verifiable claims, no invented facts (critical)

        |   factual_accuracy < 5 = automatic REJECT

SPEC JSON — WHAT IT CONTAINS AND WHO READS IT
================================================================================

{
  "storyboard": "..."       WRITTEN BY: creative director
                            READ BY: nothing (extracted to _storyboard.md)
                            DELETED: yes, popped before spec flows downstream

  "id": "slug",             READ BY: all stages (file naming)
  "label": "BRAND LABEL",  READ BY: text.py (label pill top-left)
  "scheme": "dark_red",    READ BY: text.py, renderer.py (colours)
  "voice": "...",           READ BY: voiceover.py
  "voice_script": "...",   READ BY: voiceover.py (TTS input)

  "screens": [
    {
      "text": "...",        READ BY: text.py (main headline)
      "duration": 3.5,      READ BY: renderer.py (clip/gradient length)
      "text_size": 90,      READ BY: text.py (font size)
      "panel": true,        READ BY: text.py (dark panel behind text on clips)
      "subtitle": "...",    READ BY: text.py (secondary text below headline)

      "clip_mode": null,    READ BY: researcher.py
                            null = timestamped (Gemini finds moment)
                            "ambient" = play from start for screen duration

      "clip_description":   READ BY: researcher.py (YouTube search query)
        "Event name year",

      "clip_moment": "...", READ BY: researcher.py (passed to Gemini for timestamp)
                            Describes the SPECIFIC VISUAL MOMENT to extract.
                            Different from clip_description which finds the video.

      "clip": {             WRITTEN BY: researcher.py
        "url": "...",       READ BY: renderer.py (which video to download)
        "start": 4.5,       READ BY: renderer.py (-ss seek point)
        "end": 8.5          READ BY: renderer.py (null = ambient, play for duration)
      }
    }
  ]
}

================================================================================
KNOWLEDGE BASE (clip_knowledge.py)
================================================================================

WHAT IT DOES:
  Stores human-readable descriptions of every video segment Gemini analyses.
  Before any YouTube search, checks if any KNOWN clip already matches the
  requested clip_moment — even across completely different topics.

MATCHING LOGIC:
  1. Pre-filter by keyword overlap (fast, free, Python)
  2. Send candidates + clip_moment to Gemini as a TEXT call (~$0.0001)
  3. Gemini reasons semantically: "swimmer finishing a race" matches
     "athlete reaching a goal line" but NOT "swimmer celebrating in pool"
  4. Specific match required — not just topically similar

DATA FORMAT:
  cache/clip_knowledge/{video_id}.json — one file per YouTube video
  cache/clip_knowledge/thumbs/         — one frame per known segment

VERIFICATION:
  clip_knowledge.mark_verified(video_id, start, end) — marks a clip as
  human-verified. Verified clips always appear in matching candidates.
  Unverified clips are ranked by keyword relevance.

GROWS OVER TIME:
  Every run adds new clips. After 10 runs across 10 topics, the library
  contains ~30-50 clips spanning sports, politics, science, business.
  Subsequent runs on similar topics find clips instantly without Gemini video
  analysis, saving both time and money.


================================================================================
KNOWN ISSUES AND PLANNED IMPROVEMENTS
================================================================================

IN PROGRESS / DESIGNED:

  1. PER-SCREEN AUDIO MODE (audio_mode field)
     Problem: All clip audio is stripped. News/testimony clips need their
              original audio — the spoken content carries information that
              screen text cannot replace.
     Design:  audio_mode: null/"voiceover" | "clip_audio" | "ducked"
              clip_audio = keep original audio, voiceover pauses
              ducked = clip audio at 30%, voiceover at full
     Files:   spec.py, renderer.py, assembler.py, voiceover.py,
              creative_director.txt
     Status:  DESIGNED, NOT BUILT

  2. LANDSCAPE CLIP CROP (blurred background fill)
     Problem: 16:9 source videos crop to center 31% of frame — looks zoomed.
     Fix:     Scale clip to 1080px wide (full frame visible), fill
              remaining vertical space with blurred/darkened background.
              Standard TikTok/Reels approach.
     File:    vidpipe/renderer.py
     Status:  IMPLEMENTED (2026-05-30)

KNOWN LIMITATIONS:

  - Content reviewer uses its training data for factual checking. Claims
    about events after its knowledge cutoff may be scored incorrectly.
    Factual accuracy of briefs is the USER's responsibility.

  - clip_moment is only as good as the creative director's imagination.
    If the moment doesn't exist in the video, Gemini returns low confidence
    and the screen falls back to gradient. This is correct behaviour.

  - Parallel runs (multiple topics simultaneously) share some cache dirs.
    clip_knowledge writes are atomic (temp→rename) but search/metadata
    caches are not locked. Use one run at a time for clean results.

  - Gemini occasionally returns fractional timestamps (0-1 normalized) instead
    of seconds. researcher.py detects and corrects these. Wide fractional
    ranges (>0.25) are treated as low-confidence and rejected.


================================================================================
QUICK REFERENCE — COMMON OPERATIONS
================================================================================

RUN A NEW BRIEF:
  python orchestrate.py "Brief text here. Use dark_red, scandal angle."

RE-RUN WITH EXISTING SPEC (skip creative director):
  python orchestrate.py specs/my-spec.json

FORCE REGENERATE SPEC (ignore brief cache):
  python orchestrate.py "Brief..." --force-regen

SKIP RESEARCH (re-render existing clips):
  python orchestrate.py specs/my-spec.json --skip-research

DRY RUN (see estimated cost before spending):
  python orchestrate.py "Brief..." --dry-run

VERIFY A CLIP IN KNOWLEDGE BASE:
  python -c "import clip_knowledge; clip_knowledge.mark_verified('VIDEO_ID', start, end)"

LIST UNVERIFIED CLIPS:
  python -c "import clip_knowledge; [print(s.clip_id, s.description[:60]) for s in clip_knowledge.list_unverified()]"

CLEAR BRIEF CACHE (force creative director to regenerate):
  del cache\briefs\*.json
